# 📝 Мини-блог на Django

**Элегантный личный блог, созданный по всем канонам минимализма.**  
Чистый Django, никакой админки, никакого JavaScript — только серверный рендеринг и утончённый дизайн.

---

## ✨ Возможности

- 📄 **Лента постов** — только опубликованные записи, от новых к старым.
- 🔍 **Детальный просмотр** — полный текст, статус, дата создания.
- ✍️ **Создание и редактирование** через красивые формы.
- 🗑️ **Удаление с подтверждением** — без случайных потерь.
- 🎨 **Стильный интерфейс** — авторский CSS, Google Fonts, мягкие тени и анимации.
- 📱 **Адаптивная вёрстка** — выглядит отлично на всех устройствах.

# ✅ Todo List — Django + SQLite + Docker

Минималистичное веб‑приложение для управления задачами.  
Без JavaScript, с красивым интерфейсом на чистом HTML + CSS.  
**Идеально для изучения основ Django.**

---

## 🧩 Функциональность

- 📋 Просмотр всех задач с сортировкой по дате создания (новые сверху)
- ➕ Добавление задачи (название, описание, отметка о выполнении)
- ☑️ Отметка задачи как выполненной / снятие отметки
- 🗑 Удаление задачи
- 🔐 Админ‑панель Django (`/admin/`) для полного управления
- 🎨 Современный адаптивный дизайн без единой строчки JavaScript
- 🛡 Защита от CSRF, валидация форм, обработка ошибок 404

---

## 🛠 Технологии

- **Backend:** Python 3.12, Django 6.0.6
- **База данных:** SQLite
- **Фронтенд:** HTML5, CSS3, Google Fonts (Inter)
